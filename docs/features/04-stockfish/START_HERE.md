# 04-Stockfish — Start Here

## What is this feature?
Integrates the Stockfish chess engine for two purposes: (1) browser-side WASM for real-time computer opponent moves in games, and (2) server-side BullMQ worker for deep post-game analysis. These are two distinct integration points that share no code.
